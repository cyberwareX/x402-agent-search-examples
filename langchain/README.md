# langchain

See the top-level README for price, speed and the free trial. Set PK to a wallet key with a little USDC on Base, then run the file.

Want it as a package instead of a file? `pip install langchain-cyberwarex` ([PyPI](https://pypi.org/project/langchain-cyberwarex/), [source](https://github.com/cyberwareX/langchain-cyberwarex)) has the same two tools as `CyberwarexSearch` and `CyberwarexReadPage`, with the free trial built in and readable errors.
